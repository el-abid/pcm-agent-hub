# Agent Annuaire PCM

Ce prompt remplace l'ancien agent « Support ». Le fichier de référence est
`docs/prompts/annuaire-agent.md`.

L'agent Annuaire utilise `pcm_doc` et donne les contacts exacts : astreinte
maintenance, astreinte électricité, PCC, agent de station, avec la condition
d'appel et les horaires.
